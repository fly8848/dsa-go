## 推进规则

- 一次只推进一个主题，每个主题按：AI 讲思路 → 搭架子 → 手写实现 → 写测试 → review → 测试全绿，再进入下一个。
- **深度收缩**：P0 主题保留完整流程（实现+核心测试），跳过压力测试与对照学习等深度环节；P1 主题只做实现和最小验证；P2 主题暂停。
- 每个主题目录放实现与测试；重要心得写进目录内的短笔记。
- 以本表状态为准，不凭假设推进。

## 刷题策略（实操）

- **以刷题为主线，学习按需回补**：面试能力来自刷题，数据结构只是弹药；主题学习只为支撑刷题，遇到不会的主题回去补那一小块，不线性预习。
- **每个主题循环**：主题快速实现（P0 流程）→ 该主题刷 10-15 道经典题（主力）→ 下一主题。
- **刷题平台用 CodeTop（codetop.cc）**：按公司聚合高频题，筛"中厂"标签，刷目标公司真考过的题；不用 LeetCode 按难度盲刷。
- **刷题标准**：独立写出 + 讲得清思路即可，符合中厂算法面强度，不死磕 Hard。
- **主题必刷清单**（随进度补充）：
  - 栈与队列：有效括号、最小栈、用栈实现队列、用队列实现栈、单调栈入门
